| 术语 | 英文 | 意思 |
|---|---|---|
| 正式组 | working set | 做到 RIR 3 以内、计入训练量的组。热身组不算 |
| RIR | reps in reserve | 一组结束时，估计还能以标准动作完成的次数 |
| 力竭 | failure | 以标准动作再也完成不了下一次。RIR 0 |
| 机械张力 | mechanical tension | 肌纤维在收缩对抗外力时受到的拉力，增肌的主要信号 |
| 运动单位 | motor unit | 一条运动神经和它支配的所有肌纤维 |
| 大小原则 | size principle | 神经系统从小到大依次动用运动单位，任务越难动用得越全 |
| 肌肥大 | hypertrophy | 肌纤维变粗、肌肉体积增大 |
| 训练量 | volume | 通常指每个肌群每周的正式组数 |
| 间接组折算 | fractional sets | 复合动作里不是主要目标的肌群，按半组计入训练量 |
| 频率 | frequency | 同一肌群每周练几次 |
| 多关节动作 | compound exercise | 同时活动两个以上关节的动作，如卧推、划船、腿举 |
| 单关节动作 | isolation exercise | 只活动一个关节的动作，如弯举、侧平举、腿屈伸 |
| 向心、离心 | concentric, eccentric | 肌肉缩短着发力的阶段；肌肉被拉长同时仍在发力的阶段 |
| 拉长位 | lengthened position | 动作中目标肌肉处在较长状态的那一段 |
| 幅度 | range of motion, ROM | 一次动作中关节活动的范围 |
| 渐进超负荷 | progressive overload | 随着能力提高，逐步增加重量、次数或组数 |
| 双重进阶 | double progression | 先在同一重量上把次数加到区间上限，再加重量 |
| 减量 | deload | 有意降低训练压力的一段时间，用来消除累积疲劳 |
| 分化 | split | 把不同肌群分配到一周里不同训练日的方式 |
| 超级组 | superset | 两个动作交替做，中间只短暂休息 |
| 延迟性肌肉酸痛 | DOMS | 训练后一到两天出现的肌肉酸痛 |
| 身体重组 | body recomposition | 同时减少脂肪、增加肌肉 |
| 瘦体重 | lean body mass | 体重中除去脂肪的部分，包括肌肉、水分、器官和骨骼 |
| 基础代谢 | basal metabolic rate, BMR | 完全静息状态下一天消耗的热量 |
| 总消耗 | total daily energy expenditure, TDEE | 基础代谢加上活动、消化等的一天总消耗 |
| 热量缺口 | energy deficit | 摄入低于消耗的差额 |
| 肌肉蛋白质合成 | muscle protein synthesis, MPS | 肌肉里新蛋白质的合成速率 |
| 肩胛平面 | scapular plane | 身体正侧面往前约 30° 的平面，肩关节在这里活动最顺 |
| 髋铰链 | hip hinge | 躯干保持挺直、以髋为轴前倾的动作模式 |
| 憋气发力 | Valsalva maneuver | 吸气后憋住、绷紧躯干完成发力，提高脊柱稳定性，同时短时升高血压 |
| 低能量可用性 | low energy availability, LEA | 摄入的能量长期不够支撑训练消耗，会影响月经、骨骼、代谢等多个系统 |
| 分腿蹲 | split squat | 前后脚分开的单侧下蹲，居家练腿的主力动作 |
| 轴向负荷 | axial loading | 重量沿脊柱纵向向下传递的受力方式 |
| 髌股关节 | patellofemoral joint | 髌骨和大腿骨之间的关节，膝盖前侧疼痛多和它有关 |
| 双能 X 线吸收法 | DXA | 用于测骨密度和体成分的检查 |
| Z 评分 | Z-score | 和同年龄、同性别人群平均值相比的骨密度偏差，年轻人看这个 |
| 荟萃分析 | meta-analysis | 把多项研究的数据合并起来做统计分析 |
| 元回归 | meta-regression | 荟萃分析的一种，用来看效果怎样随某个变量变化 |
| 随机对照试验 | randomized controlled trial, RCT | 把参与者随机分组、比较不同干预的试验 |
| 肌电研究 | EMG study | 测量动作中肌肉电活动的研究，反映即时激活，不直接等于长期增长 |
