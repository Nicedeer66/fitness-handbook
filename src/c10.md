::: warn 先读这一段
这一章整理的是公开的指南和研究，目的是帮你判断什么时候该停、什么时候该去看医生，以及和医生谈得更具体。它不能代替医生、康复师对个人情况的判断。正在治疗的疾病和正在用的药，不因训练而自行调整。
:::

::: key
- 有心血管、代谢、骨骼或关节方面的疾病，或者训练中出现过胸痛、头晕，**开始之前先问医生**。
- 慢性病大多不是不能练的理由。多数情况下，规律运动本身就是治疗的一部分。
- 保护脊柱，要管住的是**受力方式**：避免带负荷的大幅弯腰、扭转和突然的冲击。有靠背或胸托、重量不压在肩上的器械是最稳妥的起点。
- **分清三种痛**：肌肉酸痛、关节的机械性疼痛、炎症性疼痛。处理方式完全不同。
- 胸痛、胸闷、摔倒后的剧烈背痛、手脚麻木无力，**立刻停下并就医**。
:::

## 什么情况先问医生

开始一项新的训练计划之前，下面任何一条符合，先和医生谈一次：

- 有心脏病、高血压、糖尿病、肾病，或者家里有人年纪不大就因心脏问题猝死。
- 有视网膜病变、青光眼、疝气，或者近期做过眼科、腹部手术。
- 活动时出现过胸痛、胸闷、心慌、头晕或晕倒。
- 有骨质疏松、骨量偏低，或者有过轻微外力就骨折的经历。
- 有脊柱、髋、膝、肩方面的疾病或手术史，或者正在因为关节、腰背的问题看医生。
- 有炎症性关节病、风湿免疫类疾病，或者正在长期用激素、免疫抑制剂。
- 怀孕或产后不久。

问医生的时候，问得越具体越有用。与其问“我能不能健身”，不如问：哪些动作要避免，负重有没有上限，冲击性的活动（跑、跳）能不能做，出现什么情况要停。

## 慢性病不等于不能练

::: ev
- 世界卫生组织的身体活动指南认为，有慢性病的成年人同样应当进行有氧活动和每周至少两天的肌肉力量训练，在能力范围内尽量达到一般人群的推荐量[@who2020]。
- 欧洲抗风湿病联盟关于体力活动的建议认为，面向普通人群的活动建议（有氧、肌肉力量、柔韧、神经肌肉训练）同样适用于炎性关节炎和骨关节炎患者，而且是安全的[@rauschosthoff2018]。
:::

实际的做法是：在医生给出的范围里练，选负荷可控的动作，从比健康人更轻的重量开始，加得更慢一些。

## 脊柱怎么受力

把动作按脊柱的受力方式分成三类：

| | 脊柱怎么受力 | 例子 |
|---|---|---|
| 支撑下的训练 | 躯干靠在垫子上，负荷主要加在四肢 | 腿举、腿屈伸、腿弯举、坐姿推胸、下拉、胸托划船 |
| 中立位的轴向负荷 | 脊柱保持自然曲度，重量沿脊柱向下传 | 深蹲、站姿推举、负重行走 |
| 弯曲、扭转或冲击 | 脊柱在负荷下被弯、被拧，或者瞬间受力 | 弓背硬拉、负重卷腹、负重转体、甩腰借力、跳跃落地 |

对健康人来说，三类都可以练，前提是技术正确、重量循序渐进。第三类里，弓背硬拉和甩腰借力对谁都不推荐。

腰背有伤病史、骨量偏低、有脊柱疾病，或者年纪较大的人，可以按下面的默认清单起步，再根据医生的意见放宽：

| 可以先做 | 先练动作模式，加重量等医生 | 先不做 |
|---|---|---|
| 有靠背或胸托的器械：腿举、腿屈伸、腿弯举、坐姿推胸、胸托划船 | 箱式高脚杯深蹲 | 大重量、低次数的杠铃深蹲和硬拉 |
| 史密斯卧推（设好安全挡）、高位下拉、坐姿绳索划船（躯干保持不动） | 髋铰链：徒手或持长杆练动作模式 | 负重卷腹、仰卧起坐、俄罗斯转体 |
| 绳索和哑铃的单关节动作 | 坐姿或器械推举 | 弓背的早安式体前屈；长时间弓背到底的拉伸 |
| 臀桥、自重或轻负荷臀推 | 负重行走 | 任何靠甩腰、后仰完成的次数 |
| 平板支撑、死虫、侧桥、鸟狗式 | | 跳跃落地；容易摔倒或有身体冲撞的运动 |
| 游泳、快走、椭圆机、固定单车 | | 别人用力帮你压、扳的被动拉伸；扳颈椎或腰椎的推拿手法 |

腿举和臀推虽然在第一栏，力仍会经过骨盆和下背。下背贴住靠垫、不追求大重量依然重要。

## 骨量偏低的人

::: ev
英国关于骨质疏松运动的共识声明建议，骨质疏松患者仍应做渐进的肌肉力量训练；所有骨质疏松患者都应调整或避免持续、反复或做到末端的脊柱前屈，带负荷时尤其如此，弯腰和搬物改用髋铰链；已有椎体骨折或多处脆性骨折的人，还要把冲击强度限制在快走的水平以内[@brookewavell2022]。
:::

这份共识的意思是：骨量偏低更需要练，而不是不练。力量训练和适度的冲击性活动是给骨骼的刺激；要改的是弯腰的方式和冲击的强度。游泳和骑车对关节友好，但不给骨骼负重刺激，不能单靠它们。

## 髋铰链

髋铰链是指躯干保持挺直、以髋关节为轴向前倾的动作模式。弯腰捡东西、从地上搬箱子、做罗马尼亚硬拉，正确的做法都是它。

{{fig:hinge|**左：躯干是一块直板，前倾来自髋关节。右：腰背弓起，负荷落在脊柱上。**}}

先不加重量练会这个模式：

- 背对墙站，离墙一脚的距离。膝盖微屈，臀部向后去碰墙，上身自然前倾，腰背保持挺直。
- 拿一根长杆贴在背后，后脑、上背和骶骨三点始终贴着杆做前倾。任何一点离开，就是脊柱动了。
- 感觉对了，大腿后侧会有拉伸感，腰不会累。

这个模式值得尽早学会，因为它在日常生活里每天都要用。动作熟练以后，健康人再逐步加重量；腰背有问题的人，加重量前先问医生。

## 三种痛

| | 肌肉酸痛 | 关节的机械性疼痛 | 炎症性疼痛 |
|---|---|---|---|
| 位置 | 练过的肌肉，按压时痛 | 关节缝隙或肌腱，位置固定，和某个动作对得上 | 下背、臀部深处，或者关节、足跟、肌腱附着点，和训练量对不上 |
| 时间 | 练后 1–3 天最重，通常一周内消退 | 做特定动作时出现，休息后减轻 | 后半夜和清晨最重 |
| 晨僵 | 没有，或几分钟 | 没有，或很短 | 常超过 30 分钟 |
| 活动后 | 活动开了减轻 | 负重越多越重 | 活动后好转，久坐久躺后加重 |
| 怎么办 | 照常训练，换个部位练 | 用下面的评分尺；持续就停并就诊 | 不是练出来的，去看风湿免疫科；训练降到轻量活动 |

年轻人如果腰背痛持续三个月以上，而且符合右边一栏的特点，值得去风湿免疫科查一下，不要只当成练伤或久坐。

{{fig:pain_scale|**一把简单的尺子。** 适用于关节的机械性不适，是临床康复里常用的经验做法。}}

需要立刻停止训练并就医的情况（另外，发热或感染期间先暂停训练）：

- 运动中出现胸痛、胸闷、明显气短、心慌，或头晕到眼前发黑；用力时突然出现剧烈头痛。
- 摔倒、碰撞或用力之后，新出现的剧烈背痛或颈痛。
- 手脚麻木、无力，大小便控制出现异常。
- 关节明显红、肿、热。
- 高强度训练后肌肉剧痛、肿胀，同时尿色变深。这可能是横纹肌溶解，要尽快去急诊。

## 伤病或慢性病发作时

有慢性病的人，症状会有波动。关节或腰背的症状加重时：

- 一般不需要完全停下来。很多炎症性的疼痛活动后反而好转，卧床只会更僵。
- 把力量训练降到很轻：器械动作保留一半的组数，每组 RIR 4 以上，或者只做活动度练习、步行和游泳。
- 不做新动作，不试新重量。
- 症状持续或加重，联系医生，由医生决定是否调整治疗。
- 缓解之后，用一到两周逐步回到原来的量，不要第一天就恢复全部组数。

第 4 章说的减量周处理的是训练带来的疲劳。疾病波动不是一回事，不要用“减量一周再冲”来对待。

## 膝盖

膝盖的处理方法在第 9 章：先选压力小的角度范围，用评分尺控制，肿胀、卡住、打软时就诊。补充一点：膝盖如果不是在负重时痛，而是没有外伤却晨起僵、肿、发热，要当成关节炎症去看风湿免疫科，这和练出来的机械性疼痛不同。髋部深处或腹股沟持续疼痛、髋关节活动变差，也要及时就诊（骨科或风湿免疫科）；长期用激素的人尤其不要拖。
